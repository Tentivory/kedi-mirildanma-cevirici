# Kedi Mırıldanma Çevirici

## Bilimsel Devrim: İnsan Dilini Kedi Mırıldanmasına Çeviren Tek Araç

Bu repository, insanlık tarihinin en önemli buluşlarından birini içerir. Artık kedilerin ne düşündüğünü (yaklaşık olarak) anlayabilirsiniz. Veya daha doğrusu, onlara insan gibi konuşabilirsiniz ve onlar mırıldanarak cevap verecektir.

**Bu proje kesinlikle şaka değildir.** Tamamen ciddi, bilimsel ve NASA tarafından (henüz) onaylanmamış bir teknolojidir. Dünyayı kurtarabilir. Belki de kedileri.

## Özellikler

- Gerçekten çalışır (Python 3 gerektirir)
- Her kelimeyi rastgele miyav, mır, purr kombinasyonlarına çevirir
- Yavaşça çalışır çünkü kediler acele etmez
- %100 doğru çeviri (kediler onayladı)
- Gizli siyasi mesaj içerir ama sakladık, bulamazsın

## Kurulum

```bash
git clone https://github.com/Tentivory/kedi-mirildanma-cevirici.git
cd kedi-mirildanma-cevirici
python kedi_cevirici.py "Merhaba kediler, internet sizin"
```

## Örnek Çıktı

```
🐱 Kedi Çevirisi: Miyav Mır Purr Miy 🐱
(Bu çeviri %100 doğru ve bilimseldir. Şüphe edersen kedine sor.)
```
